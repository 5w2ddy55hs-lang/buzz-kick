# 画面の意匠メモ

[anything-frontend-art-direction](https://github.com/RNA4219/anything-frontend-art-direction)（MIT）の手順と確認表を当てて決めた内容。

## 結果画面

- 題材と主役：試合後に出る「配信のふり返り」。利用者が最初に知りたいのは「今日の配信はどうだったか」で、答えは評価（急上昇1位など）・いいね・最大同接・登録者の増減。次の判断は「もう1試合／ガチャる／やめる」。
- 見本：配信サービスのアナリティクス画面（同時視聴者数の推移グラフ）を題材の手掛かりにした。制作側の原文と実物の画面は今回は開いていないため、見本の実見は**未確認**。
- 比較（同じ試合データ・幅1280／390／320で並べた）
  - A（以前）：評価の下にスロット・XPが続き、右側に13個の同じ形の数値タイルが並ぶ。タイルの見た目がどれも同じで、いいねだけ枠色が違う。狭幅では「もう1試合」まで大きくスクロールが要る。
  - B（採用）：左に「スコア → 評価 → 3つの数値（いいね・最大同接・登録者）→ 同時視聴者数グラフ」、右に報酬（スロット・XP・登録者）と、折りたためる「プレーの記録」。
- Bで見えるようになったこと：390幅の初期表示で評価・3つの数値・グラフ・報酬に加えて「もう1試合」まで届く。グラフにゴール（ミント）・失点（ピンク）・乱入（黄）の点が乗り、同接が「いつ・何で」伸びたかが読める。13個の数値は表に下げ、一覧性は保った。
- 退けた点：320幅では見出し「配信おつかれさま」が2行になる。操作と数値は残るので保留。

## 確認表で直したこと

- 明滅：画面フラッシュは1秒に3回までに制限（ガチャの超激レア演出などで連続していた）。
- 動き：OSの「視差効果を減らす」設定ではガチャの演出を省いて結果を即表示。ガチャ背景の放射光・NEWボタンの虹色・プレビューの回転など、内容と並んで流れ続ける装飾の動きは5秒前後で止まる。
- ダイアログ：開いている間は背面を操作不可（inert）、Esc で閉じる（やり込み・ログインボーナスを追加）、閉じたら開いたボタンにフォーカスを戻す。
- キーボード：タイトルでボタンにフォーカスしたまま Enter を押すと、そのボタンと同時に試合まで始まっていた不具合を修正。
- 320 CSS px：タイトル・ガチャ・やり込み・遊び方・結果画面で横はみ出しなし。
